================================================================================
                          TASK LIST — PROOF OF CONCEPT
================================================================================
  Goal: A small, playable loop where workers gather resources automatically,
        the player builds a barracks, recruits troops, earns gold, and tries
        to destroy the enemy portal.
================================================================================

STAGE 1 — SCENE & MAP
--------------------------------------------------------------------------------
  [X] Create a basic 2D scene with a flat play area
  [X] Place player castle on the left, enemy portal on the right
  [X] Add a few trees and rocks to the map as harvestable objects
  [X] Set up a simple camera (static or basic follow)

STAGE 2 — WORKERS & RESOURCE GATHERING
--------------------------------------------------------------------------------
  [X] Create a Worker scene that automatically moves to trees/rocks and harvests
  [X] Trees yield Wood when fully chopped, rocks yield Stone when fully mined
  [X] Player starts with 1 worker
  [X] Add a "Recruit Worker" button to HUD (costs Gold)
  [X] Workers pick the nearest available resource node and work autonomously
  [X] Display current resource counts (Wood / Stone / Gold) in a simple HUD

STAGE 3 — BUILDING
--------------------------------------------------------------------------------
  [x] Create a Barracks scene that can be placed on cleared land
  [x] Add a "Build Barracks" button to the HUD (costs Wood + Stone)
  [X] Block building on tiles that still have trees/rocks

STAGE 4 — TROOPS
--------------------------------------------------------------------------------
  [X] Create a basic Troop scene (simple sprite, stats: HP, speed, damage)
  [X] Barracks spawns a troop when the player recruits one (costs Gold)
  [X] Recruiting a troop increases passive Gold income
  [X] Troops auto-walk from player side toward the enemy portal
  [X] Troops deal damage to the enemy portal on contact

STAGE 5 — ECONOMY
--------------------------------------------------------------------------------
  [X] Passive Gold income increases each time a troop is recruited
  [X] Gold is spent on: recruiting workers, recruiting troops, upgrades (later)
  [X] Display Gold income rate in HUD (e.g. "+3 gold/sec")

STAGE 6 — ENEMY PORTAL
--------------------------------------------------------------------------------
  [X] Enemy portal spawns basic troops at set intervals until it is destroyed
  [X] Enemy troops auto-walk toward the player castle and deal damage
  [X] Player castle and enemy portal both have visible HP bars

STAGE 7 — WIN / LOSE CONDITIONS
--------------------------------------------------------------------------------
  [X] Player wins when enemy portal HP reaches 0
  [X] Player loses when their own castle HP reaches 0
  [X] Show a simple win/lose screen with a restart option

STAGE 8 — POLISH (POC MINIMUM)
--------------------------------------------------------------------------------
  [X] Workers show a visual indicator when harvesting
  [X] Troops, player castle, and enemy portal show HP bars
  [X] HUD is readable and not overlapping game elements
  [X] Game is restartable without closing
